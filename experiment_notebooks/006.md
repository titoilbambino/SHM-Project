# 006 — Sadeghi CNN and attention model for endpoint strain

Does the CNN and self-attention architecture described by Sadeghi Eshkevari improve held-out `SB01_x` estimates relative to the [005 TCN](005.md)?

## Model

New implementation based on [dissertation §2.2.2, Fig. 2.2](https://preserve.lehigh.edu/_flysystem/fedora/2024-11/SadeghiEshkevari_lehigh_0105A_12856.pdf#page=37). The original reconstructs two filtered strain traces from five accelerometers over 25 s. Here the input is 500 × 75 (5 s at 100 Hz), and the target is the gauge value at the final input timestamp, in MPa.

- Embed each sample into 20 features. Apply three residual convolution blocks (convolution, ReLU, layer normalization) and one final convolution. Concatenate the embedding and four convolution outputs to obtain 100 features at each of the 500 timestamps.
- Add positional embeddings, apply two MLP/self-attention/layer-normalization blocks and decode through width 128 to one scalar. All 500 keys and values are available to both attention blocks. Only the final query is needed from the second block for the endpoint loss.
- Implementation choices where the chapter leaves details open: width-5 convolutions with same padding, four heads of width 25, a learned 500 × 100 position table, a two-layer embedding (20, 20), one 100-unit ReLU projection per attention block and a two-layer ReLU decoder (128, 128). All inputs end at or before the target timestamp. 191,109 trainable parameters (005: 11,601).

## Training and evaluation

Use the [001 recording split](001.md) and the training and scoring protocol of [005](005.md). Dense training uses 247,118 eligible endpoints in the full fit. Each validation run fits three `_02` sweeps and holds out the fourth. Adam (0.001), batch size 512, seed 0, MPS. Check validation MSE eight times per pass. Checkpoints become eligible after one full pass. Stop after 20 checks without improvement or at 200 passes. Select the final fit duration by rounding the median best pass. Compare per-recording and mean RMSE and R² to the saved 005 run at the same 1,981 `_01` endpoints. Both network design and parameter count change in this comparison.

## Held-out test results

The final 006 fit used all four `_02` recordings for 483 updates. The four validation fits, final fit and scoring took 46.4 minutes on MPS. The saved 005 run took 14.1 minutes, with five epochs selected for its final fit.
