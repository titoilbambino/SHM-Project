# 001 — Strain estimation on held-out recordings

## Question and data

How accurately can we estimate `SB01_x` from bridge acceleration on another run of the same bridge, with the structural state and shaker setting represented in training?

Use the eight undamaged (`UDS`) sine sweeps (`SM`). There are two repeats for each combination of shaker position (`P1` off centre, `P2` at midspan) and direction (`Y` lateral, `Z` vertical). Each run has 75 bridge acceleration channels and synchronized gauge readings at 100 Hz. `SB01_x` is the longitudinal gauge on the south lower chord. The file reports its values in MPa. [HBTA dataset](https://zenodo.org/records/14632942)

## Primary split

Train on all four `_02` recordings from 22 September 2020. Test on all four `_01` recordings from 23 and 27 September 2020. Each row pairs the same shaker setting and structural state across the two sets. The model is fitted jointly on the four training runs.

These are full recording durations from the HDF5 metadata. That is about 41.5 minutes per set and 83.1 minutes total. The training and test sets contain 249,114 and 249,278 synchronized sample times, respectively, before any windowing.

Temperature, wind and train passage are recorded per run. Each pair differs in date, temperature and train passage. Both P1 pairs also differ in wind category. The paired scores measure transfer across these changes together. Each setting has two repeats, which gives too little independent variation to estimate the effects of individual conditions.

## Validation within the training set

If model selection or early stopping requires validation, rotate through the four whole training recordings. Setting labels identify the exact `_02` recordings in the pairing table. The four `_01` recordings remain the test set in every fold.

Each validation fold holds out one shaker setting from the fit because there is one training run per setting. Use the validation scores for selection, then refit the selected configuration on all four `_02` recordings before evaluating the `_01` recordings.

## Evaluation

- Assign recordings to splits before constructing windows. Each window stays within one recording. Fit learned preprocessing on the fit recordings for each fold and on all four training recordings for the final fit. Apply it unchanged to validation and test data.
- Use the same eligible target timestamps across models within each test recording. Report RMSE in MPa and R² per recording, plus the equally weighted mean of the four recording scores for each metric. Include a constant baseline using the mean of the training targets.
- For the reverse check, swap the two recording columns above. Fit on all four `_01` runs (2,492.74 s) and test on all four `_02` runs (2,491.10 s). If validation is needed, rotate through the same four settings using the exact `_01` runs in the test column. Each reverse fold has 1,868.65–1,871.28 s for fitting and 621.46–624.09 s for validation. Freeze the evaluation and model selection procedure before scoring either test set.

Earlier experiments used portions of these recordings. This split defines a retrospective benchmark for transfer between runs of the same bridge.
